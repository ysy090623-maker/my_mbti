아니 학교수행에서 이거 깃허브에 뭐하라는데 ㅠㅠ 어케하는지모르겟어

8분 전

Claude 응답: 아 학교 수행평가면 아마 "깃허브에 올려서 링크 제출"이거나 "깃허브 페이지로 배포"하라는 걸 거예요.

아 학교 수행평가면 아마 "깃허브에 올려서 링크 제출"이거나 "깃허브 페이지로 배포"하라는 걸 거예요. 하나씩 따라오시면 돼요, 어렵지 않아요!

  1. 1
    깃허브 계정 만들기github.com 에 접속해서 이메일로 무료 회원가입을 해요. 이미 계정 있으면 로그인만 하면 돼요.
  2. 2
    새 저장소(repository) 만들기로그인 후 오른쪽 위 '+' 버튼 → 'New repository' 클릭. 이름은 영어로 아무거나 (예: mbti-pokemon) 입력하고, Public으로 설정한 뒤 'Create repository' 버튼을 눌러요.
  3. 3
    index.html 파일 업로드하기저장소 페이지에서 'Add file' → 'Upload files' 클릭. 아까 받은 index.html 파일을 마우스로 끌어다 놓고, 아래 초록색 'Commit changes' 버튼을 눌러요.
  4. 4
    GitHub Pages 켜기 (사이트로 보이게 하기)저장소 상단 메뉴에서 'Settings' 클릭 → 왼쪽 메뉴에서 'Pages' 클릭. 'Branch' 항목을 'main'으로 선택하고 'Save' 눌러요.
  5. 5
    완성된 링크 확인하기1분 정도 기다린 후 같은 Pages 화면을 새로고침하면 초록색으로 'Your site is live at https://아이디.github.io/저장소이름/' 이라는 링크가 떠요. 이 링크를 열어보면 웹페이지가 바로 보여요!
  6. 6
    제출하기이 링크(https://아이디.github.io/저장소이름/)를 복사해서 수행평가에 제출하면 끝이에요. 저장소 주소(github.com/아이디/저장소이름)도 같이 요구하면 그것도 복사해서 내면 돼요.

순서대로만 따라가면 5분 안에 끝나요. 막히는 단계 생기면 스크린샷 찍어서 보여줘도 돼요, 어디서 막혔는지 바로 봐줄게요.

보낸 메시지: 인덱스파일을 마우스로 어케끌어

인덱스파일을 마우스로 어케끌어

Claude 응답: 어렵게 생각 안 하셔도 돼요, 그냥 파일 탐색기에서 마우스로 잡아서 브라우저 화면 위에 놓으면 돼요.

어렵게 생각 안 하셔도 돼요, 그냥 파일 탐색기에서 마우스로 잡아서 브라우저 화면 위에 놓으면 돼요. 순서로 알려드릴게요.

  1. 1
    파일 위치 열어두기바탕화면이나 다운로드 폴더에서 index.html 파일이 보이는 폴더 창을 하나 열어두세요. (윈도우면 파일 탐색기, 맥이면 Finder)
  2. 2
    깃허브 업로드 화면도 같이 열어두기브라우저에서 'Add file → Upload files'를 눌러서 나온 화면(점선 박스에 'Drag files here'라고 써있는 화면)을 그대로 켜 두세요. 화면을 반씩 나눠서 폴더 창과 브라우저 창을 동시에 보이게 하면 더 편해요.
  3. 3
    마우스로 눌러서 끌기폴더 창에 있는 index.html 파일 위에 마우스 커서를 올리고, 왼쪽 버튼을 누른 채로 손을 떼지 말고 그대로 브라우저의 점선 박스 위까지 이동하세요.
  4. 4
    박스 위에서 손 떼기(놓기)점선 박스 위에 파일 아이콘이 올라간 게 보이면, 그때 마우스 왼쪽 버튼에서 손을 떼세요. 파일이 업로드 목록에 추가돼요.
  5. 5
    Commit changes 누르기파일이 목록에 뜬 걸 확인했으면, 아래 초록색 'Commit changes' 버튼을 눌러서 완료하세요.

혹시 드래그가 잘 안 되면, 점선 박스 안에 있는 **"choose your files"**라는 파란 글씨를 그냥 클릭해도 돼요. 그러면 파일 선택창이 뜨고, 거기서 index.html을 찾아서 더블클릭하면 똑같이 업로드돼요. 드래그보다 이 방법이 훨씬 쉬울 수 있어요!

네 컴퓨터시군요! 그럼 이렇게 해보세요.

  1. 1
    1단계: 대화창에서 파일 박스 찾기지금 이 대화창을 위쪽으로 스크롤해서 올려보세요. 제가 처음에 만들어드렸던 답변을 찾으세요. 그 답변 안에 흰색이나 회색 네모칸 박스가 있고, 그 안에 'index'라는 글자와 함께 파일 모양 아이콘이 보일 거예요.
  2. 2
    2단계: 마우스 올리면 나오는 다운로드 버튼 누르기그 네모칸 박스 위에 마우스 커서를 올리면, 박스 오른쪽 위에 작은 아이콘들이 나타나요. 그 중에 아래방향 화살표(↓) 모양 아이콘이 다운로드 버튼이에요. 그걸 클릭하세요.
  3. 3
    3단계: 자동 저장됨버튼을 누르면 화면 데서 아무 창도 띄지 않고, 자동으로 내 컴퓨터의 '다운로드' 폴더에 파일이 저장돼요. 보통 브라우저 왼쪽 아래(크롬) 또는 오른쪽 위에 다운로드된 파일이 잠깐 뜨면서 알려줘요.
  4. 4
    4단계: 다운로드 폴더에서 파일 찾기윈도우: 바탕화면에서 '내 PC' 또는 '파일 탐색기' 아이콘을 누르고 왼쪽 메뉴에서 'Downloads(다운로드)' 폴더를 클릭하세요. 맥: 하단 독(Dock)에서 웃는 얼굴 모양(Finder)을 누르고 왼쪽에서 'Downloads'를 클릭하세요. 거기서 index.html 파일이 보이면 성공이에요!

다운로드 폴더에서 index.html 파일 찾으셨나요? 찾으셨으면 그다음 깃허브 업로드 단계로 넘어가시면 돼요. 안 보이면 말씀해 주세요, 화면 캡처해서 보여주셔도 좋아요.
